# AI 访谈调研平台 - 系统x需求设计文档

> **版本**: v1.10  
> **定位**: AI 主持的智能访谈调研平台 

## 1. 系统概述
前端必须使用，vue3+ts进行开发，后端使用python进行开发。

### 1.1 产品定义

一个由 AI 主持的访谈调研平台。研究人员创建项目并上传问卷，AI 自动生成访谈流程；参与者通过会议链接进入视频对话，AI 根据流程进行语音访谈；所有对话实时保存并存入知识库，支持后续 AI 分析问答。



### 1.2 核心用户角色

| 角色 | 职责 |
|------|------|
| **管理员（Admin）** | 系统配置、用户管理、角色权限分配、API Key 管理 |
| **研究人员（Researcher）** | 创建项目、上传问卷、生成访谈流程、查看调研文档、AI 分析 |
| **参与者（Participant）** | 通过会议链接参与视频访谈、与 AI 语音对话 |
| **AI 主持人（AI Moderator）** | 执行访谈、按流程提问、分析回答、结束对话 |

### 1.3 核心工作流

```
项目创建 → 访谈内容上传 → AI生成访谈流程 → 生成会议链接 → 视频访谈 → 
ai对话 → 访谈结束 → 存入知识库 → AI分析问答
```

#### 3.2.3 访谈决策 Prompt 设计

你是一位专业的调研访谈主持人。你的任务是按照预定的问卷流程，与参与者进行自然对话，收集高质量的信息。


【你的行为准则】
1. 必须覆盖所有问题，不能跳过
2. 每个问题需要根据回答质量决定是否追问（最多 {max_follow_up} 次）
3. 追问应该深入理解参与者的想法，而不是重复问题
4. 当判断当前问题已获得足够信息时，礼貌地进入下一题
5. 保持专业、友好、中立的访谈风格
6. 所有问题完成后，感谢参与者并结束访谈

【多模态信号理解】
- 音频：理解参与者的语义内容、情绪、犹豫、兴奋等
- 视频（如有）：观察参与者的面部表情、眼神、肢体语言
- 综合判断：参与者是否在思考、是否愿意深入探讨、是否有保留
