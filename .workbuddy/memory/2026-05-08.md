## 访谈链接 404 修复

### 问题
访问 `/interview/2` 时，前端调用 `GET /api/interviews/by-token/2` 返回 404。

### 根因
- 前端 `getInterviewLink()` 生成链接：`/interview/${interview_token || interview.id}`
- 旧数据的 `interview_token` 为空，回退到使用 `id`（如 `2`）
- 后端 `get_interview_by_token()` 只按 `interview_token` 字段查询，传 `2` 找不到记录

### 修复
- **文件**：`backend/package/yuxi/services/interview_room_service.py`
- `get_interview_by_token(token)` 增加 id 回退兼容：token 查询失败后，尝试将 token 转为 `int` 调用 `get_by_id()`
- API 容器已重启加载最新代码

## 点击开始通话 500 错误修复

### 问题
点击"开始通话"后，`POST /api/interviews/{id}/rtc-config` 返回 500，`docker logs api-dev` 显示 `400 Bad Request`（火山引擎 StartVoiceChat）。

### 根因
1. `volcengine` SDK 未安装，`from volcengine.Signer import Signer` 抛出 `ImportError`
2. 回退到 `_call_volc_api_manual` 手动签名，但实现不完整，火山引擎拒绝请求（400）

### 修复
1. `backend/package/pyproject.toml` 添加 `volcengine>=1.0.0` 依赖（pypi 最新版为 1.0.222，`>=1.1.0` 会导致依赖解析失败）
2. `api-dev` 容器内执行 `uv pip install --system volcengine volcengine-python-sdk`
3. 重写 `_call_volc_api`：
   - 使用 `volcengine.auth.SignerV4` + `volcengine.Credentials` + `volcengine.base.Request` 进行官方签名
   - 删除 `_call_volc_api_manual` fallback
   - 错误时打印日志并抛出异常（便于前端感知）
4. API 容器已重启
